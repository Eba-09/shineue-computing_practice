# Computing Practice — Шинэ Үе сургууль

Сурагч ангиа сонгоно → нэрээ сонгоно → PIN оруулна → тухайн 7 хоногийн хичээлийн слайдыг үзэж, дасгалаа хийнэ.
Багш dashboard дээр хэн аль дасгал дээр хэрхэн алдсаныг шууд харна.

Next.js 14 (JavaScript) · Supabase · framer-motion · CodeMirror. Vercel дээр үнэгүй ажиллана.

---

## 1. Supabase (өгөгдлийн сан) — 5 минут

1. https://supabase.com → Sign up → **New project** (Region: Singapore). Database password-оо хадгалж ав.
2. Зүүн цэс → **SQL Editor** → New query → `supabase/schema.sql` файлын бүх агуулгыг буулгаад **Run**.
3. **Project Settings → API** хэсгээс хоёр зүйл хуулж ав:
   * `Project URL` → `SUPABASE_URL`
   * `service_role` түлхүүр (secret) → `SUPABASE_SERVICE_ROLE_KEY`
   Энэ түлхүүрийг хэнд ч бүү өг. Зөвхөн Vercel-ийн тохиргоонд оруулна.

## 2. GitHub → Vercel — 5 минут

1. https://github.com дээр шинэ **private** repository үүсгээд энэ хавтасны файлуудыг upload хий
   (`node_modules`, `.next`, `.data` хавтсыг бүү оруул).
2. https://vercel.com → GitHub-аар нэвтэр → **Add New → Project** → repository-оо сонго.
3. **Environment Variables** хэсэгт дөрвөн утга нэм:

| Name | Утга |
|---|---|
| `SUPABASE_URL` | Supabase-ийн Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role түлхүүр |
| `TEACHER_PASSWORD` | Багшийн нууц үг |
| `SESSION_SECRET` | Урт санамсаргүй мөр, ж: `k3J9...` (32+ тэмдэгт) |

4. **Deploy**. Хэдэн минутын дараа `https://….vercel.app` хаяг гарна. Settings → Domains хэсгээс нэрийг нь сольж болно.

## 3. Анхны тохиргоо

1. `…/teacher` → нууц үгээ оруул.
2. **Анги ба сурагч** → зөвхөн өөрийн хичээл ордог ангиудыг нэм (6А, 7Б…).
   Сурагчдын нэрсийг Excel-ээс хуулж буулга. PIN автоматаар үүснэ → **PIN жагсаалт хэвлэх**.
3. **Хичээл ба слайд** → Google Drive дээр слайдаа *Anyone with the link · Viewer* болгоод линкийг тухайн хичээлийн мөрөнд буулгаад Хадгалах.
4. Ангийн тохиргоо:
   * **Огноогоор** — сурагчид тухайн 7 хоногт хуваарьт байгаа хичээлээ автоматаар харна.
   * **Гараар** — амралт, нөхөж орох хичээл, өөр сэдэв үзэх үед аль хичээлийг харуулахаа өөрөө сонгоно.

## 4. Хичээл дээр

* Сурагчид слайд үзэнэ → **Дасгал** таб → дасгал бүр өөрийн хугацаатай. Хугацааг сервер тоолдог тул хуудсаа дахин ачаалсан ч цаг эхнээс нь эхлэхгүй.
* **Check my work** — буруу бол сануулга гарна, засаад дахин шалгана. Эхний удаад зөв = 1, засаж зөв = 0.5, хугацаа дууссан = 0 (eSchool-ийн 0 / 0.5 / 1).
* Үндсэн дасгалуудаа дуусгасан сурагчид **Нэмэлт дасгал** нээгдэнэ.
* Төгсгөлд сурагч өөрийн дүн, буруу хариултуудаа хардаг. Dashboard дээрх **Хариултыг нээх** товчийг дарвал зөв хариулт ч харагдана.
* Dashboard 10 секунд тутам шинэчлэгдэнэ. Нүдэн дээр дарвал сурагчийн илгээсэн бүх хариулт гарна. Компьютер гацсан сурагчийн хичээлийг тэндээс дахин эхлүүлж болно.

## 5. Агуулга

* `content/lessons.js` — 6, 7, 8-р ангийн бүх хичээл, огноотойгоо (Year Plan + багшийн бүртгэл).
  Огноо, нэрийг энд засна. `date: null` бол зөвхөн гараар сонгоход харагдана.
* `content/exercises/<lessonId>.js` — нэг хичээлийн дасгалууд. Шинэ хичээл нэмэхдээ аль нэг файлыг хуулж засаад `content/exercises/index.js`-д нэг мөр нэмнэ.

Дасгалын төрлүүд:

| type | Юу хийх | Хариулт шалгах |
|---|---|---|
| `mcq` | Нэгийг сонгох | `answer: 2` (0-ээс эхэлнэ) |
| `output` | Гаралтыг таамаглах | `accept: ['0 1 2 3']` — мөр/зай хамаагүй |
| `fill` | `___` нүдийг нөхөх | `accept: [['float'], ['end+1','1+end']]` — нүд бүрт; `re:` бол regex |
| `fix` | Кодыг засах | `accept: ['бүтэн зөв код', ...]` — зай, догол (2 эсвэл 4), хашилтын төрөл хамаагүй |
| `order` | Мөрийг дараалалд оруулах | `lines` (зөв дарааллаар), `orders` (зөв хувилбарууд) |

Хариултууд зөвхөн сервер дээр шалгагддаг — сурагч хөтчөөс хариултыг харах боломжгүй.
